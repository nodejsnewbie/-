## 1. 设计硬约束（来自前序确认，不可违背）

| #   | 约束                                 | 来源              | 对信息架构的影响                                                   |
| --- | ------------------------------------ | ----------------- | ------------------------------------------------------------------ |
| 1   | 后台**只有 2 个角色**                | 第 3 步           | 不做复杂 RBAC；权限 = 角色 + 区域数据范围                          |
| 2   | 运营管理员**兼资质审核与结算**       | 第 3 步           | 两者同角色；**必须提供审计日志入口**（内控缓解措施）               |
| 3   | **单县试点，30–50 名技师**           | 第 3 步           | 区域层级浅（县 → 网格两层）；不需为超大数据量做复杂设计            |
| 4   | **三端交付**：后台 + 技师端 + 农户端 | 第 3 步           | 后台不做移动端适配优先；技师端/农户端任务导向                      |
| 5   | **无地图定位**                       | 纪要（年费 5 万） | 派单以**网格**为单位；不出现公里数、到达分钟数                     |
| 6   | **无线上商城**                       | 第 3 步           | 后台**无**商品管理、订单、购物车、支付；农资只做**溯源与出库绑定** |
| 7   | **无 OCR / 无人脸核身**              | 第 3 步           | 审核页 = 看证件图 + 人工给结论，**不出现任何识别率**               |
| 8   | **开方是结算前置**                   | 第 3 步           | 技师端必须有开方入口；工单状态机保留 5 步                          |
| 9   | **服务净值与农资金额分离**           | 第 3 步           | 工单详情与结算页需**分别显示**两项金额                             |
| 10  | 一物一码溯源节点必须真实留痕         | R6                | 溯源查询页展示**真实节点与时间**，无节点就显示为空，**不得补造**   |

## 3. 企业后台信息架构

### 3.1 一级导航（建议 6 项）

| #   | 一级模块       | 主要使用者 | 关键操作                                               |
| --- | -------------- | ---------- | ------------------------------------------------------ |
| 1   | **运营总览**   | 两者       | 只读看板（**仅真实指标**）                             |
| 2   | **工单调度**   | 区域督导   | 派单、改派、异常工单处置、履约跟踪                     |
| 3   | **技师与资质** | 运营管理员 | 入库审核（通过/驳回/退回补正）、启停用、许可证到期预警 |
| 4   | **农资与溯源** | 运营管理员 | 批次登记、赋码、出库绑定、溯源码查询                   |
| 5   | **分红结算**   | 运营管理员 | 生成月度结算、复核、发起代发、明细查询                 |
| 6   | **系统设置**   | 运营管理员 | 角色权限、区域网格、档位与税率配置、**审计日志**       |

### 3.2 与现有原型的差异（必须调整）

| 现状                                                        | 建议                                   | 理由                                                                    |
| ----------------------------------------------------------- | -------------------------------------- | ----------------------------------------------------------------------- |
| 「资质与合规审核」是**抽屉**（`QualificationAuditDrawer`）  | **升为独立页面**，置于「技师与资质」下 | 它有独立的 4 态状态机与批量处理需求，抽屉承载不了；且 R5 要求审核可留痕 |
| 「技术人员管理」                                            | 改名「**技师与资质**」                 | 名称需覆盖资质维度                                                      |
| 无审计日志入口                                              | **新增「审计日志」**（系统设置下）     | 审核与结算同一人兼任，**必须有事后追责能力**（内控缓解措施）            |
| KPI 卡含窜货预警、OCR 比对率、平均到达时长、在线技师 386 人 | **全部移除**                           | 能力不存在 / 与试点规模矛盾（R4）                                       |
| 派单候选卡显示「距离 2.1km / 预计 22 分钟」                 | 改为「**网格内 / 跨网格**」            | 无定位能力（约束 5）                                                    |
| 一级导航 7 项                                               | 收敛为 **6 项**                        | 资质审核从抽屉变为模块内页面，一级不再单列                              |

## 4. 技师端信息架构（任务导向，4 个 Tab）

| #   | Tab                 | 内容                                                                     | 优先级 |
| --- | ------------------- | ------------------------------------------------------------------------ | ------ |
| 1   | **待办 / 我的工单** | 待接单、进行中、已完成；按状态分组                                       | P0     |
| 2   | **工单作业**        | 接单 → **到场打卡** → 填服务记录与用量 → **开具电子处方** → 上传现场凭证 | P0     |
| 3   | **我的分成**        | 本月预计、历史结算单（应付/预扣税/实发三项）、当前档位与累计业绩         | P0     |
| 4   | **我的资质**        | 许可证信息与有效期、到期提醒                                             | P1     |

> **约束**：Tab 2 的步骤顺序**不可跳过**——打卡与开方都是硬前置（R5 / R7）。
> **注意**：技师端不做 GPS 水印（无定位能力），打卡只记录时间与网格。

## 7. 关键数据流

```
农户报单 ──▶ 工单(pending_dispatch) ──▶ 督导派单 ──▶ 技师接单
                                                        │
                              打卡(时间+网格) ◀──────────┘
                                    │
                          服务记录 + 开方(处方号) ──▶ 农资出库绑定(溯源码)
                                    │
                              农户验收签字 ──▶ completed ──▶ 计入月度结算基数
                                    │
                          看板指标 ──┴── 溯源节点留痕
```
