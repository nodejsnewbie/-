# 客户需求确认问卷（分层）

> ⚠️ **本文件已降级为「内部备查」，暂不发给客户。**
> 原因：它按「**面谈对象**」分层且共 65 题，适合**方案评审**与访谈排期，不适合**讨论阶段 + 微信沟通**（微信发不出去，客户也不会填）。
> 当前对外推进请用 → [`discovery-questions.md`](discovery-questions.md)：**按需求深度分层，第一层仅 7 题，附可直接复制的微信话术。**
> 本文件保留的价值：**§2 的 20 条假设前提登记表**，以及第三、四层细化时可直接取用的题库。客户确认后再逐项回填。

> **用途**：向客户确认需求。此前 3 轮答复均来自**开发方（需求对接人）的判断**，不是客户确认过的事实。
> **因此本问卷的核心不是「提问」，而是「把我们的理解摆出来让客户确认或纠正」**——每题都给出「当前我们的理解」，客户可直接打勾或改写。
> **关联文档**：确认后逐项回填 [field-audit](field-audit.md)、[product-card](product-card.md)、[amoeba-policy](amoeba-policy.md)、[information-architecture](information-architecture.md)，并据此修订 [AGENTS.md](../../AGENTS.md) 的红线。

## 1. 一页速览：影响最大的 9 条

> 这是 24 道 P0 题中**影响面最广的 9 条**——任一条被推翻，都会连带改动多份文档。适合作面谈开场。

| #   | 我们的理解（待确认）                                                                | 若理解错误会怎样                                           |
| --- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 1   | 平台做 **5 类服务**：植保诊断、农资配送维保、飞防（无人机）、农机巡检维保、土壤检测 | 工单服务类型枚举、技师资质匹配规则、小程序报单表单全部要改 |
| 2   | 本期交付 **三端**：企业后台 + 技师端小程序 + 农户端小程序，**不含线上商城**         | 影响工期与范围；含商城则本期做不完                         |
| 3   | 企业后台使用者**只有 2 个岗位**：运营管理员、区域督导                               | 权限模型（R8 红线）与全部页面的可见性设计                  |
| 4   | **农户验收签字本期必做**，且是结算的唯一触发点                                      | 若不做，结算基数无从确定；若后置，本期无法自动结算         |
| 5   | 分红资金**只来自服务收入**（不含产品销售提成、团队利润、公司利润池）                | 结算公式、档位系数、财务预算全部重算                       |

| 7   | 农资成本**可按工单分摊**（分摊方式未定）                                            | 若无法分摊，则「服务净值」口径不成立，分红公式要重设计     |
| 8   | 资质审核是**纯人工**：审核员看证件照片给结论，**无 OCR、无人脸核身**                | R5 红线的校验手段与审核页面设计                            |
| 9   | 按**网格**派单（县 → 网格两级），**本期不做地图定位**                               | 派单匹配算法与数据结构；影响 5 万元/年地图预算决策         |

## 9. 面谈建议

**顺序**：先 L1（定范围与规模）→ 再 L4（定合规边界，因为合规会否掉功能）→ 再 L3（定钱）→ 最后 L2 / L5 / L6。

**理由**：L1 决定做多大，L4 决定哪些不能做，L3 决定分红能不能算。L2 的流程细节在边界确定后再谈，返工最少。

**两个提问技巧**：

1. **不要问「要不要」，要问「现在实际怎么做」**——例如不要问「需要电子处方吗」，而问「技师现场开药，现在填什么单子？谁签字？」。实际流程比意愿更可靠。
2. **对每个「我们的理解」逐条让客户打勾**，比开放式提问更快、更少遗漏，也便于日后追责。

**需要客户提供的材料清单**（比问问题更有效）：

- 现行分成/激励制度文件（若有）
- 区域/网格划分表
- 技师名录与证件样例
- 农药经营许可证样例（注意脱敏）
- 产品清单与登记证号
- 服务价目表（若已有）
